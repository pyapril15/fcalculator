# 📦 Calculator App - Latest Release

## ✨ Version 1.0.0

🗓️ **Release Date:** April 22, 2025  
🔖 **Tag:** `v1.0.0`

---

## 🚀 New Features

- ✅ Cross-platform support for **Android** (`.apk`) and **Windows** (`.exe`)
- ✅ Responsive and modern calculator UI
- ✅ Basic arithmetic operations: addition, subtraction, multiplication, division
- ✅ Real-time calculation updates
- ✅ Dark/light mode compatibility *(if applicable)*

---

## 🛠 Improvements

- Improved UI layout for better screen utilization
- Clean separation of logic and UI using **GetX** for state management
- Refactored codebase into modular architecture

---

## 🐞 Bug Fixes

- Fixed layout overflow on smaller Android screens
- Corrected decimal input behavior
- Improved keyboard focus handling on Windows
